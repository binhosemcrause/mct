# Design System

> Version: 0.1 · Last updated: 2026-10-12

---

## Colour

### Dominant — warm white & charcoal black (background / text)

| Token        | Hex       | Usage                       |
| ------------ | --------- | --------------------------- |
| `dominant-1` | `#F4F5EE` | Main background             |
| `dominant-2` | `#F1E8DC` | Secondary background, cards |
| `charcoal`   | `#2B2630` | Primary text                |

### Primary — blue

| Token          | Hex       | Usage                              |
| -------------- | --------- | ---------------------------------- |
| `primary-1`    | `#8DB4D6` | Soft fills, highlights             |
| `primary-dark` | `#1F6299` | Main actions, links, active states |

### Secondary — purple

| Token            | Hex       | Usage                         |
| ---------------- | --------- | ----------------------------- |
| `secondary-1`    | `#D6C6E3` | Soft fills, tags, backgrounds |
| `secondary-dark` | `#7A45A8` | Supporting emphasis           |

### Accent — orange

| Token         | Hex       | Usage                         |
| ------------- | --------- | ----------------------------- |
| `accent-1`    | `#FF854D` | Highlights, badges, call-outs |
| `accent-dark` | `#993608` | Accent text, pressed states   |

### Footer

| Token   | Hex       | Usage                     |
| ------- | --------- | ------------------------- |
| `paper` | `#FEFAF5` | Footer background         |
| `ink`   | `#163B5F` | All footer text and links |

## Typography

### Font families

| Role     | Font           | Fallback                |
| -------- | -------------- | ----------------------- |
| Headings | `Josefin Sans` | `system-ui, sans-serif` |
| Body     | `Josefin Sans` | `system-ui, sans-serif` |

### Type scale

| Token        | Name                 | Font         | Weight         | Size |
| ------------ | -------------------- | ------------ | -------------- | ---- |
| `h0`         | Display Heading      | Josefin Sans | Semibold (600) | 72   |
| `h1`         | Screen Title Heading | Josefin Sans | Semibold (600) | 60   |
| `h2`         | Section Heading      | Josefin Sans | Semibold (600) | 48   |
| `item-title` | Item Title           | Josefin Sans | Bold (700)     | 36   |
| `paragraph`  | Paragraph Text       | Josefin Sans | Regular (400)  | 32   |
